# Banking System

A command-line banking application written in Python. It uses classes to manage bank accounts and record transactions.

## Features

- Create a savings account
- Deposit and withdraw money
- Check an account balance
- View transaction history
- Apply a monthly account update

## Requirements

- Python 3

## Run the program

Open PowerShell in the project folder and run:

```powershell
python main.py
```

Follow the on-screen menu to use the banking features.

## Project files

- `main.py` — starts the program and displays the menu
- `bank.py` — manages bank accounts
- `account.py` — defines account behavior
- `transaction.py` — records and displays transactions
